**Why did the backend use a NoSQL MongoDB database?**

No SQL databases are better if you need to store a large set od data. In our case were storing user data as well as trip data. That eventually will pile up and we need a database that can handle the influx.

**How is JSON different from Javascript and how does JSON tie together the frontend and backend development pieces?**
JSON has more structure than JavaScript. JSON is just for formatting and is not an actual language like JavaScript. The front end and back end are tied together through JSON and APIs. Requests are sent and received in JSON format

**Methods for request and retrieval necessitate various types of API testing of endpoints, in addition to the difficulties of testing with added layers of security. Explain your understanding of methods, endpoints, and security in a full-stack application.**

The methods used in the project GET, POST, PUT, and DELETE are very straightforward. GET will retrieve data without any changes to it. POST can grab specific data and also create data. PUT is used to also create or update data. DELETE is used to remove data. The endpoint determines what set of data will be accessed. Having security keeps unauthorized users from accessing the data regardless of what endpoint or method is used.
